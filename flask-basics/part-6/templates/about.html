About This To-Do List App

Welcome to the Personal To-Do List App! This application was built using Flask, a lightweight Python web framework. It helps you organize and manage your daily tasks efficiently.

✨ Features

  • ✅ Task Management: Create, view, and organize your tasks
  • 🏷️ Priority Levels: Set High, Medium, or Low priority for tasks
  • 📊 Status Tracking: Track tasks as Pending, In Progress, or Completed
  • 📱 Responsive Design: Works on both desktop and mobile devices
  • 📈 Task Statistics: View overview of your task completion

🛠️ Technologies Used

Flask Python HTML5 CSS3 Jinja2

🚀 How to Use

  1. Click "Add Task" to create new tasks
  2. Set appropriate priority and status for each task
  3. Click on any task to view its details
  4. Update task status as you complete them
  5. Use the statistics to track your progress

This app was created as part of a Flask learning exercise.

Note: Tasks are stored in memory and will reset when the server restarts.
